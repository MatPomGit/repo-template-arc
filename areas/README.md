# Linie naukowe

Linie przechowuje `areas/index.json`. To klasyfikacja projektów, nie polecenie kopiowania ich manuskryptów. Utwórz dokumentację każdej linii tylko wtedy, gdy istnieją co najmniej dwa związane projekty albo wspólne decyzje metodologiczne. Przykłady ARC Neuro: `ndd`, `affect`, `cognition`, `social`, `psychometrics`.
