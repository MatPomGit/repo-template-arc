# Harmonogram wdrożenia programu

- **P0:** ustalenie zakresu i głównego właściciela artykułów; inwentaryzacja istniejących projektów `msc-*` i starszych `arc-*`.
- **P1:** rejestry projektów, manuskryptów, zależności, linii naukowych i witryn bez kopiowania danych.
- **P2:** weryfikacja zdalnych SHA oraz test kontrolowanego pobierania submodułów, jeśli faktycznie potrzebne.
- **P3:** generacja i niezależna redakcja witryny GitHub Pages, bez informacji prywatnych i surowych pomiarów.
- **P4:** migracja tylko uzasadnionych projektów, z mapą starych URI, historią Git, DOI i rollback.

Wydawanie pakietów `app-*`/`lib-*` nie jest warunkiem utworzenia tego programu; to późniejszy etap.
