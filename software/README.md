# Zależności oprogramowania

Repo `app-*` i `lib-*` są samodzielne. Projekty `msc-*` deklarują wersje wydania, SHA i konfigurację dla konkretnego eksperymentu; program ARC jedynie indeksuje relacje. GitHub Packages, GitHub Releases i Unity UPM są mechanizmami dystrybucji, nie zamiennikami repozytoriów projektów naukowych.
