# Polityka publikacyjna programu

Każdy `msc-*` ma własną stronę GitHub Pages, jeśli materiały zostały zatwierdzone do otwartej publikacji. Program może publikować wyłącznie osobno zatwierdzony katalog `pages/`, wybrane streszczenia i zweryfikowane DOI/URL; dokumentacja `docs/` nie jest źródłem witryny. Preprinty trafiają do uprawnionych repozytoriów preprintowych; prerejestracje do właściwej usługi rejestracyjnej. Żaden DOI, status accepted/published ani wynik nie może zostać wpisany bez dowodu. Prawa czasopisma, licencje i etyka są weryfikowane indywidualnie.
