# Rejestr decyzji architektonicznych (ADR)

ADR wyjaśniają **dlaczego** przyjęto zasadę, nie dublują aktualnych danych `portfolio/` ani zapisów w `PROJECT_STATE.yaml`.

| ADR | Temat | Status |
| --- | --- | --- |
| [0001](0001-canonical-ownership.md) | Jeden kanoniczny właściciel artykułu | proposed |
| [0002](0002-publication-boundaries.md) | Granice publicznego katalogu i Pages | proposed |
| [0003](0003-hybrid-arc-ownership.md) | Lokalna i zewnętrzna własność manuskryptu ARC | proposed |

Nowy ADR ma: datę, status `proposed/accepted/rejected/superseded`, kontekst, alternatywy, proponowaną decyzję, konsekwencje, dowody i odnośniki. Projekt potomny zatwierdza decyzję na podstawie rzeczywistych ustaleń, nie samego istnienia szablonu. O zmianie zaakceptowanego ADR informuje nowy rekord i odnośnik do poprzedniego.

Przestrzegaj [limitów znaków](../documentation.md), bez usuwania krytycznych informacji o ryzyku.
