# Zasady zarządzania programem

Przyjmuj tylko projekty z kanonicznym właścicielem, repozytorium, poprawnym zakresem i określonym statusem dowodowym. Ogranicz liczbę otwartych PR zgodnie z aktualną polityką Research Autopilot. Zmiany przypisania manuskryptu, publikowanie danych, reorganizacje historii Git, przenoszenie repozytoriów i rozszerzanie uprawnień wymagają osobnej decyzji. Publikacja Pages nie może ujawniać informacji o prywatnym zapleczu automatyzacji.
