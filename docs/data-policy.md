# Dane badawcze i dostęp

Surowe pomiary psychometryczne, EEG, okulometryczne, wideo, dane dotyczące zdrowia i inne dane identyfikowalne nie trafiają do programu ARC ani do GitHub Pages. Każde `msc-*` wskazuje odpowiedni magazyn (np. kontrolowany zasób Synapse), politykę dostępu, retencji i analizy reidentyfikacji. W publicznej witrynie `pages/` znajdują się jedynie zatwierdzone metadane, bez prywatnych URL i sekretów. W publicznym rejestrze Git nie mogą występować nawet nazwy i ścieżki prywatnych projektów, niezależnie od flagi `public_listing`.
