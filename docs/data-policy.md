# Dane badawcze i dostęp

Surowe pomiary psychometryczne, EEG, okulometryczne, wideo, dane dotyczące zdrowia i inne dane identyfikowalne nie trafiają do programu ARC ani do GitHub Pages. Każde `msc-*` wskazuje odpowiedni magazyn (np. kontrolowany zasób Synapse), politykę dostępu, retencji i analizy reidentyfikacji. W publicznym portalu są tylko zatwierdzone metadane i manifesty danych, bez prywatnych URL i sekretów.
